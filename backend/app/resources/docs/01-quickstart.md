# 快速开始

## 五步流程

| 步骤 | 在哪里做 | 说明 |
|---|---|---|
| 1. 登录 | 登录页 | 用**完整邮箱**（如 `you@team.com`），账号由管理员创建 |
| 2. 传数据 | 数据集 → 上传数据集 | 选格式 → 传 zip，平台自动解压并校验字段 |
| 3. 提交任务 | 提交训练 / 提交评测 | 选算法 → 选模型 → 选数据集 → 套预设 → 提交 |
| 4. 等审核 | — | 管理员通过后自动排队、分配 GPU、启动 |
| 5. 看结果 | 任务详情 | 实时日志、loss / reward 曲线、产物文件 |

## 数据大屏

登录后的首页。左边是集群实时负载，右边是运行中的任务。

![数据大屏](/api/handbook/assets/dashboard.png)

## 提交一个训练任务

![提交训练](/api/handbook/assets/submit-train.png)

三个必填项：

- **任务名称** —— 建议写成 `模型-算法-数据集-版本`，例如 `qwen3-4b-sft-terminal-v1`
- **基础模型** —— 从模型仓库选；选中后 LLaMA-Factory 的对话模板会自动带出
- **数据集** —— 只会列出当前算法能用的类型，选不到就说明格式不对

右侧「提交摘要」会实时列出还差什么，补齐后「提交任务」按钮才可点。

## 看训练结果

![指标曲线](/api/handbook/assets/job-metrics.png)

任务详情页有五个标签页：

| 标签页 | 内容 |
|---|---|
| 概览 | 进度、关键指标、运行信息、配置摘要 |
| 实时日志 | WebSocket 推送，可过滤关键字、下载完整日志 |
| 指标曲线 | 训练看 loss / lr / reward；评测看 reward 分布与 pass@k |
| 配置与命令 | 平台生成的完整命令，可直接复制到终端复现 |
| 产物 | checkpoint、Harbor 结果目录，单个文件可下载 |

标签页支持深链接：`/jobs/<id>?tab=logs` 可以直接发给同事。
