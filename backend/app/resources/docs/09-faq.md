# 常见问题

## 登录

**用 `admin` 登录不了？**
登录名是**完整邮箱**（如 `admin@prt.local`），不是用户名。

**提示「登录状态已失效」？**
token 有效期 12 小时，过期重新登录即可。如果刚重装过平台（`data/` 被清空），
JWT 密钥会重新生成，旧 token 全部失效，也需要重新登录。

## 数据集

**上传报「缺少必需字段」？**
格式选错了，或 JSON 第一条记录的字段名不对。各格式的必需字段见[数据格式说明](#data-formats)。

**Harbor 任务集上传被拒，说缺 `environment/`？**
Harbor 会静默跳过没有环境定义的任务，所以平台在上传时就拦下来，
免得你评测完才发现少跑了一半任务。

**数据集能改名吗？**
可以，在数据集列表里编辑；但正在被运行中的任务使用时不能删除。

## 训练

**选不到我的数据集？**
选择器只列出**当前算法能用的类型**。比如选了 SFT 就只会列 `sft_alpaca` / `sft_sharegpt`。

**template 该填什么？**
选模型后会自动带出。如果显示「未在 LLaMA-Factory 模型表中匹配到」，
说明本地目录名和官方名对不上，需要手动选一个模板（右上角「模型适配速查」可查）。

**多卡怎么配？**
只填「GPU 数量」即可，平台会设置 torchrun 相关环境变量，不用自己拼命令。

**OOM 了怎么办？**
按这个顺序调：减小 `per_device_train_batch_size` → 减小 `cutoff_len` →
开梯度检查点 → 用 LoRA 代替全参 → RL 场景再调低 rollout 显存占用比例。

## 评测

**全部 reward = 0？**
先用 `oracle` agent 跑一遍：如果 oracle 也不是 1.0，问题在任务集本身
（`tests/test.sh` 或 `solution/solve.sh`），不是模型不行。

**API Key 会泄漏吗？**
数据库、`run.sh`、界面、日志里都会替换成 `***`。但同机器上 `ps` 能看到子进程的
命令行参数，共享主机上建议用只读的项目级密钥。

**pass@k 怎么算？**
`k` 就是每题尝试次数。结果会给出 pass@1..pass@k；崩掉的 trial 算失败，不会被排除在分母外。

## 大屏

**没有 GPU 数据？**
平台环境需要能 `import pynvml`（`nvidia-ml-py`）且宿主机有 NVIDIA 驱动。
缺失时其他指标照常工作。

**曲线卡住不动？**
右上角有「暂停曲线」，检查是不是暂停了；徽标显示「轮询模式」说明 WebSocket 没连上，
数据仍会每 10 秒刷新一次。

## 其他

**能同时跑几个任务？**
由「全局并发任务数」和空闲 GPU 共同决定，管理员可在系统设置里调整。

**任务记录删了，产物还在吗？**
在。删除只清任务记录和工作目录，`data/outputs/<job_id>/` 默认保留。
